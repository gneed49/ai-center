# AI Center — MVP (v0)
_Ce qu'on construit en premier. Volontairement minuscule._

## Objectif unique
Prouver UNE chose : la boucle **discute → challenge → rédige**, sur la section Projets, pour un type « projet dev ». Si ce moment fait « waouh », le reste de la vision est justifié.

## Périmètre v0
- **Section Projets** : créer un nouveau projet ; historique de tous les projets.
- **Création guidée** : une étape de **configuration** (modale/manuelle) pour l'obligatoire — nom du projet, type de projet, contexte de départ, connecteurs (listés, branchement plus tard).
- **Types de projet** : commencer par « projet dev classique », extensible à d'autres types ensuite.
- **Template après config** : dans la sidebar, une **sous-section = un dossier par projet**. À l'intérieur, des **sections internes** selon le template : Produit, Design, Tech (pas de code au début ; Tech = spécifications).
- **Remplissage** : le contenu des sections n'est PAS saisi à la main → l'IA **interviewe, challenge, puis rédige**.

## Connecteurs (cibles — PAS dans le premier build)
Cursor (dev), Figma (design), Notion / Linear (gestion), Slack (comms).

## Ce qu'on NE fait PAS en v0
Omniprésence sur chaque page, vocal, auto-ingestion du contexte, connecteurs réellement branchés, toutes les sections internes complètes d'un coup.

## Arbitrage proposé (à valider par Geoffrey)
Première **tranche verticale** = créer un projet dev → l'IA t'interviewe → l'IA rédige la page **Contexte** du projet. Prouver ce flux de bout en bout AVANT d'ajouter les sections Produit/Design/Tech complètes et les connecteurs.
