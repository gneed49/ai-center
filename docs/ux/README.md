# UX

Les concepts actuels illustrent le parcours `Credits v2` et le passage Produit → Tech.

Ils expriment plusieurs principes :

- le chat reste un outil contextuel secondaire ;
- le projet, ses décisions et ses livrables dominent l’interface ;
- le graphe est rendu visible par ses conséquences, sans imposer un canvas ;
- la Decision Inbox centralise les arbitrages proactifs ;
- l’expérience mobile privilégie les décisions courtes plutôt qu’un desktop compressé.

Les images sont des concepts de direction, pas encore des spécifications pixel-perfect validées.

La référence d’implémentation du MVP se trouve dans
[ai-center-design-system.md](ai-center-design-system.md). Elle relie les
concepts actifs aux tokens, composants, comportements et règles responsive.
