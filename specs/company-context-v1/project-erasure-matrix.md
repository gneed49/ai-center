## Références polymorphes

Tous les UUID publics des lignes possédées sont comparés aux chaînes JSON exactes présentes dans les lignes conservées de la même société ; le contrôle inverse détecte aussi une référence d’une ligne possédée vers un autre objet projet. Cela couvre notamment `edges`, `model_runs.source_public_ids`, les identifiants d’origine des connaissances, les provenances de messages, les snapshots de sources et les réponses d’idempotence.

Le contrôle est volontairement conservateur : une réponse de commande non expirée ou un audit partagé peut empêcher une purge. Il ne modifie pas cette ligne pour forcer le passage. Une UUID noyée dans du texte libre n’est pas une référence canonique détectable exhaustivement ; l’opération ne prétend pas effacer toutes les mentions textuelles dans d’autres projets.
