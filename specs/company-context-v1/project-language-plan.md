# CC-053 — Parcours projet et transmission en langage métier

Le formulaire de création annonce encore deux scopes alors que cinq agents
sont créés. Les étapes de transmission exposent des termes d'implémentation
(control plane, gate, ContextPack, handoff) dans les actions principales.

Corriger les textes des parcours existants : création d'un projet partagé,
cinq agents (généraliste, Produit, Commercial, Lead technique, Développement),
validation des éléments produit puis transmission du contexte à un autre agent.
Conserver les identifiants techniques dans les API et les détails de provenance.
Ne pas promettre une exécution de code ni un outil externe déjà connecté.

Acceptation : création, reprise d'erreur, validation bloquée/périmée et
transmission réussie conservent leur comportement ; les tests navigateur
emploient les nouveaux libellés accessibles. Vérifier les écrans compacts.
