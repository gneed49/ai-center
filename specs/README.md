# Spécifications

Une spécification décrit une évolution avant et pendant son implémentation.

## Structure

```text
specs/<feature-slug>/
├── spec.md
└── plan.md
```

Une spec doit relier l’intention, les décisions existantes, le comportement attendu, les critères d’acceptation et les preuves de réalisation. Le plan décrit ensuite le découpage technique et la validation.

Les templates se trouvent dans `_template/`.
